Weekly Summary:

Week 1 - HTML Fundamentals
Created two basic HTML documents using Visual Studio Code and Sublime Text. 
Practiced using HTML document structure, headings, paragraphs, and title elements to display simple content on a web page.

Week 2 - Semantic & Multimedia
Practiced using semantic HTML elements to organize web page content. 
Worked with multimedia elements, including images and video, to make web pages more informative and engaging.

Week 3 - CSS Basics
Learned how to apply CSS styles to HTML elements to improve the appearance and layout of web pages. 
Practiced using CSS rules and Bootstrap to create a more organized and responsive design.

Week 4 - JavaScript Basics and DOM Manipulation
Practiced JavaScript fundamentals, DOM manipulation, and event handling to make web pages interactive. 
Explored updating page content dynamically and responding to user actions.

Week 5 - JavaScript Functions and Bootstrap
Worked with JavaScript functions and Bootstrap components to improve website functionality and presentation. 
Practiced organizing code into reusable functions and creating responsive user interface elements.

Week 6 - API & Client Storage
Explored API integration and client-side storage to understand how web applications retrieve information and save user preferences or data in the browser.

Week 7 - MiniFullStackStarter
Developed a full-stack CRUD application using Node.js, Express.js, and MongoDB. 
Implemented features to add, display, edit, and delete user records, with an HTML, CSS, and JavaScript frontend connected to the backend API.
